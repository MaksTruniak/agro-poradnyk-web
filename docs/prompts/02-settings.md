### 3. Навігація

### 4. Дані

#### 4.1 Завантаження (при відкритті екрана)

1. Сесія → `uid = session.user.id`, `email = session.user.email`.
2. Профіль:
   ```
   supabase.from('users')
     .select('name, first_name, last_name, company_name, phone, region, city, role, roles, address,
              edrpou, iban, bank_name, legal_address, avatar_url, is_verified, verification_requested')
     .eq('id', uid).single()
   ```
   - Якщо є `first_name` → `first_name`, `last_name || ''`.
   - Інакше якщо є `name` → розбити по пробілу: перше слово — ім'я, решта — прізвище.
   - Решта полів — значення або `''`; `is_verified`, `verification_requested` — `false` за замовчуванням.
3. Лише для `role === 'seller'`: `seller_profiles.select('*').eq('user_id', uid).single()`
   (`company_name, region, phone, description, delivery_options, pickup_address`, запам'ятати `id`).
4. Області Нової Пошти — **окремо, не блокуючи екран** (як на сайті з `onMounted`):
   `getAreas`, сортування за `Description` через `localeCompare(…, 'uk')`; помилка → порожній список.

Поки йде крок 2–3 — скелетон: дві картки-заглушки (висота 256 і 160) з пульсацією.

**Ролі в цьому екрані:**
- `role` — поле `users.role` (НЕ активний профіль з `agro_active_profile`) — так на сайті.
- `userRoles = roles?.length ? roles : [role || 'farmer']`.
- `isAgronomist = role === 'agronomist' || userRoles.includes('agronomist')`.
- `isSeller = role === 'seller'` (на сайті `MARKETPLACE = false`, але цей блок у налаштуваннях **не** прихований
  прапорцем — показуй за роллю, як на сайті).

#### 4.2 Збереження профілю (кнопки «Зберегти» в блоках «Профіль» і «Реквізити» — одна й та сама дія)

```
supabase.from('users').update({
  name: `${first_name} ${last_name}`.trim(),
  first_name, last_name,
  company_name: company_name || null,
  phone,              // у масці +38 (0XX) XXX-XX-XX (див. 5.2)
  region, city,
  address: address || null,
  edrpou: edrpou || null,
  iban: iban || null,
  bank_name: bank_name || null,
  legal_address: legal_address || null,
}).eq('id', uid)
```
Перед запитом: телефон непорожній і не проходить `isPhoneValid` → тост «Введіть коректний номер телефону», стоп.
Помилка запиту → тост «Не вдалося зберегти. Спробуйте ще раз.», «Збережено» не показувати.
Успіх → «✅ Збережено!» на 3 с.

**Загальне правило для всіх збережень на екрані** (профіль, аватар, ролі, магазин, доставка, верифікація):
перевіряти `error` з Supabase; при помилці — тост з текстом з п. 5, стан «збережено» не вмикати, кнопку розблокувати.

### 5. Екран — блоки зверху вниз

Фон екрана — `agro.bg #F5F8F0` (як дашборд), прокрутка, KeyboardAvoidingView.

#### 5.1 Шапка (`.dash-head`)
Білий фон, нижня рамка `rgb(224,237,204)`, padding 12/20, закріплена зверху.
- Квадрат 40×40, радіус 10, фон `rgb(238,241,227)`, іконка шестерні 22px, stroke `rgb(47,82,51)`, width 1.7 (SVG — п. 7).
- Заголовок «Налаштування» — Bitter 17 bold, `rgb(27,46,27)`.
- Підзаголовок «Профіль та параметри акаунту» — 12, `rgb(107,122,100)`.

#### 5.2 Картка «Профіль» (усі ролі)
Заголовок «Профіль» (див. стиль картки, п. 6).

**Аватар** (рядок, під ним роздільник `agro.border`):
- Коло 64×64, фон `agro.hover #EAF4DD`. Є `avatar_url` → фото (cover). Немає → перша літера імені великою
  (Bitter 24 extrabold, колір `agro #3B6D11`), якщо імені немає — `?`.
- Кнопка-outline з іконкою upload 13px: «Завантажити фото» / під час завантаження «Завантаження...» (неактивна).
- Підпис «JPG, PNG до 2 МБ» (12, `agro.light`).
- Логіка: вибір фото з галереї → розмір > 2 МБ → тост-помилка «Файл більше 2 МБ» → стоп.
  Інакше `storage.from('user-avatars').upload(\`avatars/${uid}.${ext}\`, file, { upsert: true })`,
  де `ext` — розширення файлу (з імені/URI; для HEIC/без розширення — з mimeType, наприклад `jpg`).
  Успіх → `getPublicUrl(path).publicUrl + '?t=' + Date.now()` → показати → `users.update({ avatar_url })`.
  Помилка upload → тост «Не вдалося завантажити фото. Спробуйте ще раз.»; помилка `update` → тост
  «Не вдалося зберегти. Спробуйте ще раз.» (фото не міняти). В обох випадках зняти «Завантаження...».
  Завантаження в RN: передати `ArrayBuffer` (через `fetch(uri).arrayBuffer()` або `base64-arraybuffer`) і `contentType`.

**Поля** (відступ між полями 16):
1. **Ім'я** / **Прізвище** — в один рядок, placeholder «Іван» / «Петренко».
2. **Назва компанії** — лише farmer і buyer (для інших не показувати):
   - farmer: label «Назва фермерського господарства», placeholder `Наприклад: Фермерське господарство "Колос"`
   - buyer: label «Назва підприємства або ФОП», placeholder `Наприклад: ФОП Петренко або ТОВ "Агро"`
   (_увага: placeholder'и тут інші, ніж на реєстрації — переносимо як є_)
3. **Email** — тільки читання, фон `agro.bg`, значення з сесії.
4. **Телефон** — та сама маска, що на реєстрації (`formatPhone` з модуля 01), placeholder `+38 (0__) ___-__-__`,
   клавіатура `phone-pad`, червона рамка, якщо непорожній і невалідний. Значення з БД при завантаженні теж
   пропускати через `formatPhone` (старі номери на кшталт `+380671234567` стануть `+38 (067) 123-45-67`).
5. **Область** — вибір (bottom sheet / модальний список), перший пункт «Оберіть область» (= порожньо),
   далі області НП (`Description`). Зміна області → очистити `city`, пошук і підказки.
6. **Населений пункт** — поле з автопідказками, placeholder «Почніть вводити назву...»:
   - < 2 символів → підказки сховати;
   - debounce 300 мс → `searchSettlements(q, areaRef)` (`areaRef` — `Ref` обраної області або порожньо) → перші 10;
   - список під полем (білий, рамка `agro.border`, радіус 12, тінь, макс. висота 208, скрол), пункт — `Present`;
   - тап → `city = Present`, у полі `Present`, список сховати.
   - Увага: якщо користувач надрукував текст і не вибрав підказку, `city` **не змінюється** (як на сайті).
7. **Адреса (вулиця, будинок)** — placeholder «Наприклад: вул. Шевченка 12», підпис під полем
   «Використовується при угодах для самовивозу або доставки».

Кнопка «Зберегти» / «Збереження...» (4.2), під нею «✅ Збережено!» (14, `agro`) на 3 с.

#### 5.3 Картка «Публічний профіль» (лише `isAgronomist`)
- Заголовок «Публічний профіль», опис «Поділіться посиланням — фермери зможуть знайти вас та надіслати запит на співпрацю».
- Плашка (фон `agro.bg`, радіус 12, padding 12/16): посилання `${EXPO_PUBLIC_SITE_URL}/agronomist/${uid}`
  (в один рядок з обрізанням) + кнопка з іконкою copy 13px «Копіювати» → `expo-clipboard` → «Скопійовано!» на 2 с.
- Посилання з іконкою external-link 13px «Переглянути профіль» → відкрити це посилання в браузері.

#### 5.4 Картка «Реквізити» (усі ролі)
- Опис «Використовуються для формування накладних. Заповнювати за потребою.»
- **ЄДРПОУ / ІПН** (placeholder `12345678`) і **Назва банку** (`АТ КБ «ПриватБанк»`) — в один рядок.
- **IBAN** (`UA213996220000026007233566001`).
- **Юридична адреса** (`49000, Дніпропетровська обл., м. Дніпро, вул. Шевченка 1`).
- Кнопка «Зберегти» — **та сама дія 4.2** (зберігає і профіль, і реквізити), той самий «✅ Збережено!».
  `saving`/`saved` спільні для обох кнопок (як на сайті — обидва повідомлення з'являються разом).

#### 5.5 Картка «Зміна пароля» (усі ролі)
- **Новий пароль** (placeholder «Мінімум 8 символів»), **Повторіть пароль** («Повторіть новий пароль»), обидва приховані.
- Перевірки по черзі, помилка — червоним текстом 14 під полями:
  1. `validatePassword` (з модуля 01) → її текст;
  2. не збігаються → «Паролі не збігаються» (_саме «збігаються», не «співпадають», як на сайті_).
- `supabase.auth.updateUser({ password })`; помилка → `error.message` як є; успіх → очистити поля і
  `Alert` «✅ Пароль змінено!».
- Кнопка «Змінити пароль» / під час запиту «...».

#### 5.6 Картка «Налаштування магазину» (лише `isSeller`)
- **Назва компанії** («Наприклад: AgroMaks»), **Регіон** («Наприклад: Київська обл.»),
  **Телефон магазину** («+380...»), **Опис магазину** (багаторядкове, 3 рядки, «Розкажіть про ваш магазин...»).
- «Зберегти магазин» / «Збереження...»: є `seller_profiles.id` → `update(payload).eq('id', id)`,
  немає → `insert({ user_id: uid, ...payload }).select().single()` і запам'ятати `id`. Далі «✅ Збережено!» на 3 с.

#### 5.7 Картка «Способи доставки» (лише `isSeller`)
- Чекбокси-картки (рамка 2, радіус 12, padding 12; обрано — рамка `agro`, фон `agro.hover`):
  `nova_poshta` 📦 «Нова Пошта», `ukrposhta` ✉️ «Укрпошта», `pickup` 🏪 «Самовивіз».
- Якщо обрано `pickup` — поле «Адреса самовивозу» («Наприклад: м. Київ, вул. Хрещатик, 1»).
- «Зберегти доставку» / «Збереження...»: якщо немає `seller_profiles.id` — тост «Спочатку збережіть налаштування магазину»;
  інакше `update({ delivery_options, pickup_address: pickup ? адреса : null })` → «✅ Збережено!» на 3 с.

#### 5.8 Картка «Профілі акаунту» (усі ролі)
- Опис «Профілі вашого акаунта. У кожного профілю своя підписка.»
- Чіпи наявних ролей (фон `rgb(234,240,222)`, текст `rgb(47,82,51)`, 12 semibold, радіус 8, галочка 12px):
  назви `farmer` Фермер, `agronomist` Агроном, `seller` Продавець, `buyer` Заготівельник (інше — як є).
- Під чіпами текст (12, `agro.light`): «Щоб додати профіль (наприклад, Агроном), зареєструйтесь з цим самим email і оберіть
  потрібну роль — профілі з'єднаються, і ви зможете перемикатися між ними.»
- **Кнопок додавання профілю немає** — профіль додається лише через реєстрацію (модуль 01, п. 5.4.1).

#### 5.9 Картка «Верифікація підприємства» (лише `role === 'buyer'`)
Опис «Отримайте бейдж «Перевірений заготівельник» — фермери більше довіряють перевіреним компаніям». Три стани:
- `is_verified` → зелена плашка (фон `#F0FDF4`, рамка `#BBF7D0`, іконка щита з галочкою `#16A34A`):
  «Підприємство верифіковане» / «Ваш профіль має бейдж «Перевірений заготівельник»».
- інакше `verification_requested` → жовта плашка (фон `#FFFBEB`, рамка `#FDE68A`, іконка `#D97706`):
  «Запит на розгляді» / «Зазвичай перевірка займає 1–2 робочі дні».
- інакше форма: поле «ЄДРПОУ / ІПН підприємства» (`12345678`, макс. 10 символів; **це те саме поле `edrpou`, що в «Реквізитах»**),
  підпис «Введіть код підприємства — адміністратор перевірить дані в реєстрі»,
  кнопка «Подати запит на верифікацію» / «Відправляємо...» (неактивна, якщо поле порожнє) →
  `users.update({ edrpou: trim, verification_requested: true })` → помилка: тост «Не вдалося надіслати запит. Спробуйте ще раз.»;
  успіх: жовта плашка
  (на сайті також на мить з'являється «✅ Запит надіслано! …», але її одразу замінює плашка — можна не показувати).

#### 5.10 Картка «Сесія» (усі ролі)
Кнопка «Вийти з акаунту» (рамка 2 `#FECACA`, текст `#EF4444`, радіус 12, 14 semibold) →
**та сама функція виходу, що в модулі 01** (`signOut` + очистити `agro_*`) → екран `auth`.
_Відхилення: на сайті ця кнопка не чистить localStorage (на відміну від виходу з меню) — у додатку робимо однаково правильно._

### 8. Нова Пошта (`src/services/novaPoshta.ts`, аналог `useNovaPost.ts`)

`POST https://api.novaposhta.ua/v2.0/json/`, JSON-тіло:
- `getAreas`: `{ apiKey, modelName: 'Address', calledMethod: 'getAreas', methodProperties: {} }` → `data || []`
  (поля `Ref`, `Description`).
- `searchSettlements(query, areaRef)`: `{ apiKey, modelName: 'Address', calledMethod: 'searchSettlements',
  methodProperties: { CityName: query, Limit: 15, Page: 1, RegionRef: areaRef || undefined } }`
  → `data?.[0]?.Addresses || []` (поля `Ref`, `Present`).

Решту методів (`getWarehouses` тощо) не переносимо — знадобляться в модулях угод/замовлень.
